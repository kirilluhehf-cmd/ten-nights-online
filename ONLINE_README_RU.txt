TEN NIGHTS IN A HOTEL — ОНЛАЙН-ЗАГОТОВКА

Что добавлено:
- сервер Node.js + Socket.IO;
- создание комнаты и вход по коду (до 2 игроков);
- обмен состоянием открытой камеры: игрок может видеть, какую CAM выбрал друг;
- сервер также раздаёт файлы игры.

ВАЖНО: это стартовая версия онлайн-режима, а не полностью синхронизированный кооператив. Враги, ночь, действия и проигрыш пока работают локально в каждой копии игры. Камера друга отображается как статус, но картинка его камеры не передаётся.

ЛОКАЛЬНЫЙ ЗАПУСК НА КОМПЬЮТЕРЕ С NODE.JS:
1. Распаковать архив.
2. Открыть терминал в папке игры.
3. Выполнить: npm install
4. Выполнить: npm start
5. Открыть http://localhost:3000

ПУБЛИКАЦИЯ:
Разместить всю папку как Node.js Web Service на хостинге, который поддерживает постоянный процесс Node.js и WebSocket/Socket.IO. Build command: npm install. Start command: npm start. После размещения откройте URL сервиса — игру нужно запускать через него, а не через file://.

Для игры завтра с телефона через мобильный интернет и школьные компьютеры сервер должен быть доступен из интернета. Запуск сервера только на телефоне сам по себе обычно не позволяет школьным компьютерам подключиться к нему напрямую.
